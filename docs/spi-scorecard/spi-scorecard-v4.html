      How SPI is calculated

      1. Skill Track Score (per course)

      Classroom Quizzes × 10% + Module Quizzes × 15% + Skill Assessments × 25% + Final Skill Assessment × 50%

      2. Skill Track Score → Skill Level and Points

      3. SPI = Σ Level Points ÷ Number of courses
