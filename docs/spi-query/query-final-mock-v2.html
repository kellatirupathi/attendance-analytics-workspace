How it behaves

1One open chat per category. A new issue in the same category is added to it. No duplicate queries.
2Subjects are shown once, as plain text in the header. No subject-wise status or tags.
3Adding a subject later shows one small line in the chat, so both sides see the change.
4One status per chat: Received, In progress, Waiting on student, Resolved. The team sets it.
5Student list: "N new" for unread replies, "Needs your reply" when the team asked something. A toast shows a new reply while the report is open.
6Screenshots: up to 3 per message, images only, shrunk before upload. Optional.
7Resolved chats stay in the list. A student reply reopens it.
8No name on the report? The team sees "Student" plus the start of the ID.
9Reply about one subject? The team writes it in the message. Subject chips paste the name in with one tap.
·Internal notes are never shown to the student, who sees "SPI team" and never a staff name. Only Admin and Super Admin see this page.
