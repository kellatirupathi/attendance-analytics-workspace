How it behaves (the numbers are on the screens)

1One open chat per category. A new issue in the same category is added to it, with more subjects ticked. No duplicate queries.
2Each subject has its own status: Checking or Fixed. The chat is Resolved automatically when every subject is Fixed.
3Every reply shows its subject tag. The chat title is the category, so a reply always belongs to it.
4One message box per chat. "About" defaults to all open subjects; tap one to talk about just that subject.
5Student list badges: "N new" for unread replies, and "Needs your reply" when the team asked something. A toast shows a new reply while the report is open.
6Screenshots: up to 3 per message, images only, shrunk before upload. Optional.
7Resolved chats stay in the list. A student reply on a resolved chat reopens it. A subject that is fixed can be reopened by the team.
8No name on the report? The team sees "Student" plus the start of the ID.
9Team marks subjects fixed one by one, or with "Mark all fixed". Each change tells the student in the chat.
10Team replies about chosen subjects. Internal notes are never shown to the student.
·Only Admin and Super Admin see this page. The student sees "SPI team", never a staff name.
